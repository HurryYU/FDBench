# Rights and source attribution

Ping Liu and Zihao Yu prepared FDBench. The benchmark uses source webpages from
the Design2Code `testset_final` dataset and CSS documentation from MDN contributors.
Original copyright notices and source content are retained. This compilation does
not grant a new blanket licence over third-party webpages or their embedded assets.
The authors must select the licence for their own data and code and confirm the
redistribution terms for Design2Code webpage material before a public deposit.

MDN prose is supplied under CC BY-SA 2.5. The original MDN licence is included in
`third_party/MDN_LICENSE.md`; its separate terms for code examples also apply.
KB-1 and KB-2 are frozen MDN document renders. KB-3 consists of 16 automatically
assembled quick-reference pages derived from MDN examples. Text chunking,
reference-page rendering and quick-reference assembly are recorded transformations.
`document_manifest.csv` records source URLs and hashes. MDN attribution remains
required for the text, rendered documentation and derived quick-reference pages.
